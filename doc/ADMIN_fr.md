D'autres serveurs NUT peuvent être ajoutés en éditant __INSTALL_DIR__/settings.yml:  
```
NUT_SERVERS:
  - HOST: host
    PORT: port
    USERNAME: username
    PASSWORD: password
  - HOST: host
    PORT: port
    USERNAME: username
    PASSWORD: password
etc.
```  
Le service PeaNUT Dashboard doit ensuite être relancé.
